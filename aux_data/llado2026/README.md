# llado2026

> P. Lladó, R. Daugintis, and E. D. Sena, 'Assessing localisation and localisation 
uncertainty for off-centre listening in a stereo loudspeaker setup', in 
*Proc. of the Audio Engineering Society International Conference on Audio for 
Virtual and Augmented Reality and Immersive Games (AVARIG)*, Paris, France, Jun. 2026.
<https://aes.org/publications/elibrary-page/?id=23294>


## Files required

| Path | Used by |
| --- | --- |
| `expResultsTable.mat` (variable `expTable`) | `load_listexp_data('llado2026')` – condition catalogue |
| `llado2026_allresults.mat` (variable `allResults`) | `load_listexp_data('llado2026')` – trial-level responses |
| `stimuli_KEMAR/wavfiles/<Pos>_ICTD_<ictd>_ICLD_<icld>.wav` (50 files, 48 kHz) | `stimuli/generate_stimuli.m` – pre-rendered KEMAR binaural stimuli; only needed to recompute model outputs |

## How to obtain

The data are **not yet publicly available**. They are available from the
authors on request.
