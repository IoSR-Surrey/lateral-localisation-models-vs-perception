# aux_data

Perceptual datasets and HRTFs are **not** tracked in this repository due to third-party
data and size. Only the loader/conversion code and these instructions are versioned;
every data file placed in `aux_data/` is ignored by git.

| Folder | Dataset | Availability |
| --- | --- | --- |
| `HRTFs/` | SONICOM + ARI HRTFs (8 SOFA files) | public, `download_hrtfs.m` |
| `frank2013/` | Frank (2013) VBAP localisation, centre + off-centre | public, `download_frank2013.m` |
| `ramirez2024/` | Ramírez et al. (2024) loudspeaker localisation | public, `download_ramirez2024.m` |
| `Simon2010/` | Simon, Mason & Rumsey (2010) ICTD/ICLD localisation | on request from the authors |
| `DeSena2013/` | De Sena et al. (2013) multichannel localisation | on request from the authors |
| `llado2026/` | Llado et al. (2026) off-centre ICTD/ICLD lateralisation | on request from the authors |

From the repository root, `download_dependencies` fetches every public folder
in this table (HRTFs, frank2013, ramirez2024). See the `README.md` inside each
folder for the exact files the loaders expect.
The datasets are loaded by `data_analysis/load_listexp_data.m`; stimuli are
generated by `stimuli/generate_stimuli.m`.
